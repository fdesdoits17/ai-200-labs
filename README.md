# AI-200 Labs

Preparation repository for Microsoft AI-200: Developing AI Cloud Solutions on Azure.

## Goals

- Build backend-oriented Azure AI labs
- Practice containerized deployments
- Work with vector search and RAG patterns
- Use Azure Functions, Service Bus, and Event Grid
- Secure apps with Managed Identity, Key Vault, and App Configuration
- Monitor and troubleshoot with Application Insights, OpenTelemetry, and KQL
